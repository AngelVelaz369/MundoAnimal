# Mundo Animal - Reto Individual

Proyecto desarrollado en Java que aplica los conceptos fundamentales de la Programación Orientada a Objetos (POO): herencia, abstracción (clase abstracta), interfaces, sobrescritura de métodos y polimorfismo.

---
